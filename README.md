## 📌 Proyectos Destacados

### 🤖 Plataforma Full-Stack con Agente de Voz e IA
Diseño e implementación de una API REST conectada a base de datos relacional para gestión operativa en tiempo real, integrando capacidades de *Function Calling* con modelos de lenguaje e interfaz móvil con reconocimiento de voz.

**Tecnologías:** `Java` · `Spring Boot` · `PostgreSQL` · `Gemini API` · `Flutter`

---

### 🔐 Analizador y Validador de JSON Web Tokens (Open Source)
Herramienta ligera para el análisis y validación criptográfica de **JSON Web Tokens (JWT)** orientada a la seguridad de APIs. Incluye verificación de firmas, control de expiración (`exp`), decodificación de encabezados/cargas útiles y aplicación de gramáticas formales.

**Tecnologías:** `Python` · `FastAPI / Flask` · `React` · `MongoDB Atlas` · `Redis` · `Docker`

---

### 🎓 Sistema Integral de Gestión para Plataforma de Streaming Educativo
Arquitectura de base de datos relacional y módulos administrativos desarrollados sobre **Oracle y Oracle APEX** para gestionar el ciclo completo de una plataforma educativa (estudiantes, docentes, cursos, suscripciones, pagos, evaluaciones y certificados) mediante restricciones de integridad, triggers y secuencias.

**Tecnologías:** `Oracle Database` · `SQL` · `PL/SQL` · `Oracle APEX`

---

### 🤟 Sistema de Reconocimiento de Lenguaje de Señas en Tiempo Real
Pipeline de visión por computador para el reconocimiento e interpretación de señas mediante detección de puntos clave y redes neuronales profundas (ANN / LSTM bidireccional).

**Tecnologías:** `Python` · `MediaPipe` · `LSTM / ANN` · `PIL`
