Incluye:

* Docentes
* Cursos
* Categorías
* Suscripciones
* Pagos
* Progreso académico
* Evaluaciones
* Certificados

**Tecnologías:** `Oracle` · `SQL` · `PL/SQL` · `Oracle APEX`

Proyecto enfocado en el análisis y validación de **JSON Web Tokens (JWT)**, aplicando conceptos de **lenguajes formales, gramáticas y autómatas**.
